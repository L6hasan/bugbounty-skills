DETECTION SIGNAL: any HTTP/3-QUIC-terminating edge/proxy on H2O <= commit d1f0f65269 (fixed a68cabaeb1); generally: a transport where an abort/reset path CLEARS received-range accounting while a shared buffer survives and a later "bytes available" read feeds a backend stream; a proxy with an observable body-buffer threshold (~10240) that switches to streaming at it; error banners fingerprinting the frontend.

CHAIN: attacker crafts an Automator app with a malicious `document.wflow` (primitive: authoring) -> replaces the stub binary with a symlink to the system's signed Automator Application Stub (bypass: the signing/notarization check validates the symlink TARGET) -> zip, disguise as image/pdf, deliver (user interaction: one click) -> the stub runs the attacker's workflow -> arbitrary code execution with NO quarantine prompt and NO GateKeeper check (Critical in Apple's threat model — "taking your macOS system back to 2006"; Apple bounty).
TRANSFERABLE TEST: for every launcher/stub/runner binary in an app bundle (or any install that validates "the" executable): (1) replace the executable with a symlink to a signed system/vendor copy and keep the behavior in a relative payload file — if it still runs, the check resolves the symlink while execution consumes the payload; (2) enumerate constant-path signed stubs on the OS (`/System/Library/CoreServices/...`) as symlink anchors; (3) test the same split on installers/updaters that verify one file and execute another. Rule: **a trust check that FOLLOWS a symlink validates the wrong file — the fix is to reject symlinks (lstat + hash the entry itself); test every 'replace the binary with a symlink to a trusted copy' split.**
