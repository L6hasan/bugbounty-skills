CLASS: OAuth confused-deputy TOKEN->SESSION CONVERSION — a first-party SSO/session-bridge handoff endpoint accepts ANY third-party OAuth access token (including one scoped to a single product's data) and mints a FULL first-party web session for the account owner; the session outlives token revocation (CWE-287/CWE-269).
CORE METHOD (the program summary, verbatim):

TRANSFERABLE TEST: on any product with SSO handoffs — (1) enumerate every session-MINTING endpoint (`/login_option`, `/session`, `/continue`, `/sso/finalize`, "open in web"); (2) call it with a THIRD-PARTY/low-scope OAuth access token instead of the app's own bridge credential; (3) if a web session cookie returns, diff its powers against the token's documented scope (settings write / account mutation = escalation to ATO); (4) revoke the token/integration and reuse the minted session — survival past revocation is the second defect. Rule: **a session-bridge handoff must accept only the app's own bridge credential — any endpoint that converts a third-party token into a first-party web session is an OAuth confused deputy, and the session must die with the token.**
