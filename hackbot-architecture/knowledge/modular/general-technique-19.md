CORE METHOD (the paper's own steps):
  1. CVE-2022-22536 — SAP ICM moves HTTP data between internal handlers and working processes through MPI buffers in shared memory of FIXED size 65536 bytes; HTTP headers always fit one buffer ("when a multi-MPI Buffer message arrives, the ICM will process the first Buffer only"), so a message > 2^16 bytes spans buffers and handlers preprocess from buffer 1 while the body in later buffers is flushed only when the work process needs it.
