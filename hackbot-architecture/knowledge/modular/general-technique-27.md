CLASS: XSS via NAME-context injection in framework tag builders (CWE-79) — ActionView::Helpers::FormTagHelper and TagHelper build tags from an options HASH whose KEYS are HTML attribute names, and accept the TAG NAME as an argument; when user input reaches a key or the tag-name argument it breaks out of the tag, because "their current protection does not restrict properly the set of characters allowed in the names of tag attributes and in the names of tags" (report verbatim) — the helpers' own name filtering is the broken defence.
CORE METHOD:
  1.   5.
