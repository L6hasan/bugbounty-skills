DETECTION SIGNAL: an exported/routable activity (manifest intent-filter on VIEW / app links / custom schemes) that forwards the incoming URI to an in-app browser or WebView with NO scheme allowlist (`file://`, `content://`, `javascript:` accepted); an IAB/WebView that runs with the app's own file access. Tell: `adb shell am start -n <pkg>/<activity> -d "file:///data/data/<pkg>/shared_prefs/<anything>.xml"` renders the file instead of rejecting the scheme.
CHAIN: malicious third-party app on the device (or adb / physical access) fires the router with a `file://` URI at the victim app's `shared_prefs` auth XML (primitive: unvalidated scheme routing + IAB file access) -> the IAB renders the app-private file containing the session token (escalation: cross-app read of app-private auth material) -> token replay = login as the victim (impact: ATO / sensitive info disclosure with PoC; program rated medium).
